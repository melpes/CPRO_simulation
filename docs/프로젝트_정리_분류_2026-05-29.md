  마이그레이션돼 있었음. **실제 `simulation_ver0_mod` 를 직접 import 하던 파일은 4개**:

  `T.build('simulation_ver0_mod', …)` 로 **삭제된 ver0_mod 를 간접 import** → 모두 깨진 상태였음.
